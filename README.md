# Vitrine Jornada do Saber

Painel de resultados da plataforma Jornada do Saber, feito para TV deitada e para totem vertical.

## Como usar

- Abra `index.html` em qualquer navegador (Chrome, Edge). Funciona offline. Sem internet, apenas a fonte muda para a do sistema.
- Para exibir em TV ou totem, abra em tela cheia (F11). Os slides trocam sozinhos. Tocar, clicar ou usar as setas do teclado pausa por 1 minuto.
- O layout muda sozinho conforme a tela: deitada (TV) ou em pé (totem).

## Como atualizar os números

Os dados ficam dentro do `index.html` (variável `D`). Eles foram lidos da plataforma em 13/11/2026. Para atualizar, peça ao Claude para gerar de novo a partir do banco e salvar aqui.
